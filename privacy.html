Política de Privacidade — PROR-MUSIC

Última atualização: agosto de 2026

Resumo

O PROR-MUSIC é um aplicativo gratuito, sem propaganda e sem coleta de dados pessoais. Este documento explica exatamente o que acontece com as informações usadas no app.

O que o app NÃO faz

  • Não coleta nome, e-mail, telefone ou qualquer dado de identificação pessoal.
  • Não exige cadastro ou login.
  • Não envia dados para nenhum servidor próprio — não existe um servidor coletando informações dos usuários.
  • Não usa rastreadores de publicidade nem vende dados a terceiros.
  • Não acessa contatos, câmera, localização ou qualquer sensor do aparelho.

O que fica salvo, e onde

O app guarda a estrutura das suas playlists (nomes das músicas e das listas) usando o armazenamento local do próprio navegador/aparelho (localStorage). Essa informação nunca sai do seu celular e não é acessível por nós ou por terceiros.

Arquivos de música

Quando você adiciona uma música do seu celular, o app lê o arquivo localmente para tocar — o arquivo em si nunca é enviado a nenhum servidor.

Serviços externos usados

O app se conecta a três serviços de terceiros, apenas para busca e reprodução de prévias, sob os próprios termos de uso deles:

  • Apple/iTunes Search API — para buscar músicas e prévias oficiais de 30 segundos.
  • Internet Archive — para buscar músicas de artistas independentes sob licença Creative Commons.
  • Spotify — apenas como link externo, abrindo o app/site do Spotify.

Essas conexões enviam apenas o termo que você pesquisa (ex: nome de uma música), sem nenhuma informação de identificação sua.
